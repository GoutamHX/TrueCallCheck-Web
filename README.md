## 🔍 About

**TrueCallCheck-Web** lets you search any Indian phone number and instantly get caller details — including name, father's name, address, carrier, email, and more. No app installation, no login, completely free.

> Search any Indian phone number to get instant caller details — name, father's name, address, carrier, email, document number, and more.

🔗 **Live Demo:** [goutamhx.github.io/TrueCallCheck-Web](https://goutamhx.github.io/TrueCallCheck-Web/)
🔗 **More Details:** [imgoutam.dev/projects/truecallcheck](https://www.imgoutam.dev/projects/truecallcheck)
🤖 **Telegram Bot:** [t.me/advancelookupbot](https://t.me/advancelookupbot)

## ✨ Features

- 🔍 **Caller ID Lookup** — Search any Indian number and get instant caller details.
- 👤 **Full Profile Info** — Name, father's name, address, and alternate number if available.
- 📧 **Email Info** — Fetches linked email address if available in records.
- 🪪 **Document Number** — Shows Aadhaar or other document numbers if available.
- 🛂 **Passport Number** — Displays passport number if present in the data.
- 📡 **Carrier & Location Info** — See the service provider and general region of the number.
- 🤖 **Telegram Bot** — Use [@advancelookupbot](https://t.me/advancelookupbot) on Telegram to look up numbers directly in chat.
- 💡 **Open Source** — Community-supported, customizable project — easy to extend or integrate.
- 🆓 **Free & No Login** — No account, no cost, no tracking.
- 📱 **Mobile Friendly** — Fully responsive design across all devices.
- ⚡ **Fast & Lightweight** — No lag, no clutter.

## 🚀 Getting Started

To run locally, follow these simple steps:

### 1. Clone the Repo

```bash
git clone https://github.com/goutamhx/TrueCallCheck-Web.git
cd TrueCallCheck-Web
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Start Development Server

```bash
npm start
```
